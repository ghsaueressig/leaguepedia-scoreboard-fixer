# Leaguepedia Scoreboard Fixer

A tool for automatically fixing Leaguepedia scoreboards generated from Riot match data.

## About
Leaguepedia's scoreboard parser can generate detailed match statistics from Riot match IDs, including champions, kills, deaths, assists, items, runes, objectives, and other game data.
However, scoreboards generated for some tournaments may require manual corrections before they are ready to be published on Leaguepedia. Common issues include:

- Missing team names
- Riot account names being used instead of Leaguepedia player IDs
- Different team naming conventions between tournament data and Leaguepedia
- Player aliases that cannot be identified directly from their Riot account name

Leaguepedia Scoreboard Fixer aims to automate these corrections while preserving the statistics generated by the parser.

## How it works
The project uses tournament match data to associate each scoreboard with its corresponding match through the Riot Match ID (`rpgid`).

The intended workflow is:

```text
Leaguepedia Parser scoreboard
            +
Tournament match spreadsheet
            ↓
       Riot Match ID
            ↓
      Match resolution
            ↓
    Team identification
            ↓
    Player identification
            ↓
    Corrected scoreboard
```

Whenever possible, player identification should rely on deterministic information such as team, role, known aliases, and roster data rather than nickname similarity alone.

Ambiguous player identities should not be automatically replaced.

## Project goals

- Identify matches using Riot Match IDs
- Determine blue and red teams from tournament data
- Normalize tournament team names to Leaguepedia IDs
- Resolve Riot account names to Leaguepedia player IDs
- Preserve the original match statistics
- Require manual confirmation when a player cannot be identified safely
- Produce scoreboards ready to be reviewed and published on Leaguepedia

## Development status

🚧 **Early development**

Current development focus:

1. Parse Riot Match IDs from raw scoreboards
2. Match those IDs against tournament spreadsheets
3. Identify blue and red teams

Player resolution and scoreboard generation will be implemented after the match resolution pipeline is validated.

## Scope

The fixer operates on scoreboards generated from played Riot matches.

Editorial Leaguepedia structures such as match recap sections, forfeits, and page layout are currently outside the core scope of the project.
